# 🗳️ Simulación Estocástica de Preferencias Electorales mediante Monte Carlo

Repositorio oficial del proyecto final para el curso de **Simulación Estocástica** de la **Maestría en Estadística Aplicada**.

---

## 📋 Descripción del Proyecto
Este proyecto implementa un modelo matemático y estocástico para analizar y proyectar preferencias electorales a partir de un conjunto de datos de sondeos de opinión pública. Utilizando una combinación de **Regresión Lineal Ponderada (WLS)** y **Simulación de Monte Carlo ($M = 10,000$ iteraciones)**, el modelo aborda de manera rigurosa la incertidumbre inherente a las encuestas, cuantificando el margen electoral, los intervalos de confianza empíricos, la convergencia del estimador y la sensibilidad ante posibles sesgos sistemáticos (*house effects*).
